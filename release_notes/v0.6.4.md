**Cordon 0.6.4**

Cordon is a Crystal shard that runs shell commands inside a platform-native sandbox with a configurable access policy. It works on macOS (via `sandbox-exec` / Seatbelt) and Linux (via `bwrap` / Bubblewrap), presenting both as a single clean API.

**Changes**

* **Timezone-aware commands now work on macOS** - The macOS baseline grants read access to the system timezone database. Previously any sandboxed process that formatted a local time — Ruby's `Time`, Python's `zoneinfo`, Go's `time`, anything Foundation-linked — silently fell back to UTC instead of the requested zone. No error was raised, so the symptom was wrong output rather than a failure. Custom policies that worked around this by adding timezone paths by hand can drop them.
  - `/usr/share/locale` was unaffected and needed no change; it is a real directory on macOS and was already covered by the existing `/usr/share` grant.
  - Linux was already correct — `/usr/share/zoneinfo` is a plain directory there and has been in the baseline all along.

---

**Known issues**

* `Policy#env` and `Policy#unset_env` are honoured on Linux but silently ignored by the macOS runner, which inherits the parent environment instead. See [#24](https://github.com/ModelArmy/cordon.cr/issues/24).
