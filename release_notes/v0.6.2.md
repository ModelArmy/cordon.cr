**Cordon 0.6.2**

Cordon is a Crystal shard that runs shell commands inside a platform-native sandbox with a configurable access policy. It works on macOS (via `sandbox-exec` / Seatbelt) and Linux (via `bwrap` / Bubblewrap), presenting both as a single clean API.

**Changes**

* **Confirm sandboxing actually works, not just that it's installed** - `available?` only checks that the sandbox binary is on `PATH`. `Runner#confirm` / `Cordon.confirm` runs real probes against the sandbox and reports pass/fail with captured output and a troubleshooting hint.
  - Also available as `cordon confirm` (with `--json`) from the CLI.
