**Cordon 0.5.1**

Cordon is a Crystal shard that runs shell commands inside a platform-native sandbox with a configurable access policy. It works on macOS (via `sandbox-exec` / Seatbelt) and Linux (via `bwrap` / Bubblewrap), presenting both as a single clean API.

**Changes**

* **Baseline defaults to deny all** - Prior default allowed process execution independent of read-able paths; this bypass is closed, instead offering a `system` preset with the additional access so someone using Cordon can make that decision intentional.
* **Read access allows execution** - Read paths specified in a policy will allow execution from those paths, thus limiting execution to specified paths.
* **Convenience APIs added** - While presets continue to clearly provide platform- and environ-specific policy options, forcing users to also implement the platform detection every time was not just tedium but also error-prone. Cordon now offers APIs with sensible exceptions so app can avoid the tedium while owning the capabilities.
