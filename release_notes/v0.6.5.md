**Cordon 0.6.5**

Cordon is a Crystal shard that runs shell commands inside a platform-native sandbox with a configurable access policy. It works on macOS (via `sandbox-exec` / Seatbelt) and Linux (via `bwrap` / Bubblewrap), presenting both as a single clean API.

**Changes**

* **HTTPS works on macOS when network access is allowed** - With `allow_network` enabled, the macOS runner now also grants read access to the system TLS directory, `/private/etc/ssl`. Previously the network was reachable but TLS configuration was not.
  - Linux already bound `/etc/ssl` and `/etc/ca-certificates` when network access is allowed. Coverage across distributions with other layouts is tracked separately.
* **`cordon inspect --platform macos` output is a valid profile** - The header line is now an SBPL comment (`;`) rather than `#`, so `cordon inspect ... > profile.sb` can be passed straight to `sandbox-exec -f`, as the debugging workflow in DEVELOPMENT.md describes.

---

**Known issues**

* `Policy#env` and `Policy#unset_env` are honoured on Linux but silently ignored by the macOS runner, which inherits the parent environment instead. See [#24](https://github.com/ModelArmy/cordon.cr/issues/24).
