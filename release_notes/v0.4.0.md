**Cordon 0.4.0**

Cordon is a Crystal shard that runs shell commands inside a platform-native sandbox with a configurable access policy. It works on macOS (via `sandbox-exec` / Seatbelt) and Linux (via `bwrap` / Bubblewrap), presenting both as a single clean API.

**Changes**

* **App can cordon off itself** - Adds `Cordon.relaunch`, letting a process re-sandbox itself in place rather than shelling out to a separate command — no wrapper binary needed.
