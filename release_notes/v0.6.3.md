**Cordon 0.6.3**

Cordon is a Crystal shard that runs shell commands inside a platform-native sandbox with a configurable access policy. It works on macOS (via `sandbox-exec` / Seatbelt) and Linux (via `bwrap` / Bubblewrap), presenting both as a single clean API.

**Changes**

* **Run shell scripts, not just argv, inside the sandbox** - `Runner#run` (and `Cordon.run`) now accept `shell: Bool`. With `shell: true`, `command` is a single script string interpreted by `/bin/sh -c`, so `>`, `&&`, pipes, and other shell syntax work — previously only possible by exec'ing `/bin/sh` yourself with matching argv. Off by default; existing calls are unaffected.
  - `/bin/sh` is not implicitly exec-granted — it needs the same policy grant as any other target (e.g. via `Preset::System`), same as the direct-exec path.
  - No positional-arg forwarding: `command` must be exactly one element when `shell: true`. Interpolate any variable data into the script string yourself before calling.
  - Not available on `Cordon.relaunch` / `Runner#exec` — that path stays focused on re-exec'ing the current process image.
